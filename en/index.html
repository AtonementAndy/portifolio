Movie Catalog API

Stack: C# em ASPNET Core WebAPI

I developed a Movie Catalog API using ASP.NET Core, implementing the Repository pattern and the Mediator pattern with CQRS to separate commands from queries. I employed Domain-Driven Design (DDD) to structure the project efficiently and used AutoMapper to simplify object mapping. Data persistence is handled via Dapper, connecting to a SQL Server database. The API also integrates ILogger for robust log management, ensuring scalability and maintainability. This project exemplifies a modern, solid architecture for web applications.
